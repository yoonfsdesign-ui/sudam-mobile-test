SUDAM v5.33 — 모바일 레이아웃 비교 3안

비교 버튼
- 기존
- 1안 Premium Editorial
- 2안 Meeting First
- 3안 Visual Luxury

독립 조합
- TONE 선택과 독립
- MAIN IMAGE 선택과 독립
- LAYOUT 선택과 독립
예: 2안 톤 + 이미지5 + 레이아웃1

레이아웃 1 — Premium Editorial
- Trust를 Hero 아래의 얇은 신뢰 정보 영역으로 압축
- 강점 슬라이드를 3개의 세로 Editorial 챕터로 전환
- 짝수 강점은 카피→이미지 순서로 교차 배치
- 모임 4종 2×2 카드
- 진연상은 큰 대표 카드, 수라상은 작은 후속 카드로 비대칭 구성
- 후기는 문장/후기 본문을 먼저, 사진을 뒤에 배치

레이아웃 2 — Meeting First
- 섹션 순서: Hero → Trust → 모임 → 강점 → 메뉴 → 공간 → 후기 → 위치
- 모임 4종을 큰 세로 네비게이션 카드로 강화
- 예약 목적 탐색이 먼저 보이도록 구성

레이아웃 3 — Visual Luxury
- 섹션 순서: Hero → 강점 → Trust → 공간 → 메뉴 → 모임 → 후기 → 위치
- 강점/공간 이미지를 거의 풀블리드에 가깝게 확대
- 카피는 이미지 하단에 간결하게 배치
- 메뉴는 이미지/텍스트 분할형
- 모임은 다크 챕터형 리스트로 단순화

안전성
- 기존 문구/링크/이미지 파일 변경 없음
- 기존 톤 1~4안 변경 없음
- 기존 Hero 이미지 선택 기능 변경 없음
- 레이아웃 선택은 localStorage에 별도로 저장
- 실제 DOM 노드는 삭제/복제하지 않고 순서만 이동
