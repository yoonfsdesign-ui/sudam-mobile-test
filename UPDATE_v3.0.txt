수담 모바일 가안 v3.0 업데이트

반영 내용
- 공통 섹션 타이틀 크기 통일 + 전통매듭 장식선 추가
- 메인 서브문구 변경, 신뢰 카피 크기 상향 및 하단 설명 삭제
- 수담의 강점/공간: 텍스트 위치·폰트·크기·자세히보기·페이지네이션 수정
- 모임 안내: 숫자/텍스트 확대 및 4개 서브문구 반영
- 메뉴: SIGNATURE/PREMIUM 색상 분리, 가격 아래 매듭선, 코스 설명/상담문구 수정
- 후기: 2개 후기 내 사진 가로 스크롤 강화
- 오시는 길: 수담한정식 라벨, 주소복사 버튼화, 발렛 문구/안내 수정
- 푸터: 정책링크 최상단, Family Site 6개, 한/영 소개문구, 매듭선, 필수정보 순으로 재배치

업로드
1. 압축 해제
2. 저장소 Add file > Upload files
3. index.html, css, js 폴더를 덮어쓰기
4. Commit changes
5. Actions의 Pages 배포 완료 후 Ctrl+F5

정상 v3 확인 포인트
- 모든 섹션 제목 아래 전통매듭 장식선
- 수담의 강점 슬라이드 점이 회색 캡슐 없이 큰 원형
- 모임 01~04에 긴 설명문구 표시
- 진연상/수라상 가격 아래 매듭선
- 오시는길 '주소' 대신 '수담한정식'
- 푸터 가장 위에 개인정보처리방침 등 링크
