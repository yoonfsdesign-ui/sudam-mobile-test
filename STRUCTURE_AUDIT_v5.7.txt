수담한정식 모바일 테스트 — v5.7 구조 복구 점검

확인된 문제
1) 상단 메뉴 CSS가 v5.3→v5.4→v5.5에서 동일 선택자로 반복 덮어쓰기 되어 구조가 불안정함.
2) v5.6은 site-config.js만 수정하고 index.html의 캐시 버전값을 갱신하지 않아 이전 링크 설정이 브라우저에 남을 수 있음.
3) HTML의 주요 메뉴 href가 #!이고 JavaScript 설정에 의존해, config 로딩 실패/캐시 시 메뉴 전체가 끊김.
4) ./상대경로는 메인에서는 동작하지만 중첩 페이지에서 재사용할 경우 경로가 달라질 수 있음.

복구 방식
- 기존 서브페이지/폴더는 삭제·수정하지 않음.
- 메인 index, main.js, site-config.js와 복구용 CSS 1개만 수정/추가.
- 상단 메뉴 링크를 /sudam-mobile-test/... 절대 경로로 변경.
- HTML에도 실제 href를 넣어 JS가 실패해도 메뉴가 동작하도록 함.
- main.js가 빈 config 때문에 유효한 href를 #!로 덮어쓰지 않도록 수정.
- 캐시 버전을 20261022-57로 갱신.
- 상단 브랜드바/5개 메뉴바의 최종 규칙을 recovery-v5.7.css에서 한 번만 강제 정의.
