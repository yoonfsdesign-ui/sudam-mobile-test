SUDAM v5.22b — 아이콘 미노출 수정

원인
- v5.22에서 기존 PNG를 숨긴 뒤 외부 SVG를 CSS mask로 불러오는 방식 사용

- 1~4안: inline SVG 표시
- 별도 SVG 파일 로딩에 의존하지 않음
- 하단 전화 아이콘 배경박스 제거 수정은 그대로 유지
