SUDAM v5.42 — 품질 점검 및 적용 범위
==================================

A. 정적 검사
- js/polish-v5.40.js 및 js/polish-v5.42.js Node --check 통과
- css/polish-v5.42.css tinycss2 파싱 오류 0건
- APPLY_v5.42.py Python 구문 검사 및 반복 실행(중복 링크 없음) 통과
- ZIP 압축 테스트 및 필수 파일 존재 여부 검사 통과

B. 로컬 Chromium 점검 (실제 GitHub 사이트 화면 아님)
- 화면폭: 320, 360, 375, 390, 430px × 레이아웃 1,2,3 = 15개 조합
- 점검용 HTML은 실제 DOM 클래스·요청받은 콘텐츠를 재현한 테스트 페이지.
- 모든 조합에서 document horizontal overflow 0, 모임 제목 영역 이탈 0,
  개발자가 의도하지 않은 고정 문구 넘침 0, 브라우저 JS 런타임 예외 0.
- 블루리본 5회/2027 문구, 레이아웃 2·3의 문장 줄 구성,
  1안 전환 시 원본 br 복원, 후기 이동 버튼 클릭/scrollLeft 이동,
  TOP 위치, TONE·MAIN IMAGE 독립 상태 유지: 테스트 통과.

C. 아직 확인 불가한 사항
- 원격 GitHub Pages를 Chromium에서 직접 열 수 없는 접근 제한으로
  실배포 페이지의 원본 사진·전체 기존 CSS·메뉴 예약 서브페이지까지 포함한
  실물 픽셀 시각 검수는 수행하지 못함.
- 사용자 교체 이미지의 최종 위치/작은 글자 가독성/실기기 클릭 영역은
  ZIP을 업로드한 뒤 실제 모바일에서 최종 확인 필요.
- GitHub 저장소는 읽기 권한만 확인되어 직접 배포하지 않았음.

D. 보존 원칙
- 이미지·아이콘·링크·서브페이지 파일 원본 내용 수정 없음.
- TONE, MAIN IMAGE, LAYOUT 선택/저장 이벤트는 기존 스크립트에서 운영.
- v5.41 JS의 위험한 CSS 런타임 삽입 및 강제 폰트 축소 대신
  기존 v5.40 swipe-progress 스크립트를 복원하고 신규 v5.42 JS를 명시적으로 로드.
- 2027 블루리본 추가는 사용자가 제공한 표기 요청 기준이며 외부 검증 사항 아님.
