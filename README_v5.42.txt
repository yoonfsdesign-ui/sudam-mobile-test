SUDAM MOBILE v5.42 — 디자인 및 사용성 재정비 (v5.40 기반)
============================================================

설치 전 확인
- 이 ZIP은 전체 홈페이지가 아니라 기존 v5.40 또는 v5.41 프로젝트에 추가하는 패치입니다.
- GitHub 저장소에 이미 들어 있는 기존 index.html, images, subpages, 기존 CSS/JS가 필요합니다.
- 이미지, 아이콘, 메뉴/예약 링크, 서브페이지 파일은 ZIP에 넣지 않았고 수정하지 않습니다.
- GitHub 리포지토리로 직접 업로드/배포한 것이 아니며 사용자 작업 필요.

적용 (권장: Windows)
1. GitHub에서 전체 프로젝트를 ZIP으로 받아 압축 해제합니다. 현재 코드를 백업해 주세요.
2. 해당 프로젝트 최상위 폴더(index.html이 있는 곳)에 이 ZIP 내용을 덮어씌웁니다.
3. APPLY_v5.42.cmd를 더블클릭합니다. Windows PowerShell로 index.html을 갱신하며 Python 설치는 필요 없습니다.
   Mac/Linux에서는 python3 APPLY_v5.42.py 명령을 사용할 수 있습니다.
4. GitHub에 다음 네 파일을 업로드합니다:
   index.html
   css/polish-v5.42.css
   js/polish-v5.42.js
   js/polish-v5.40.js
5. index.html.before-v5.42.bak는 개인 백업이며 GitHub에 올릴 필요가 없습니다.
6. 배포 후 모바일에서 새로고침(필요 시 Ctrl+Shift+R)하여 테스트합니다.

index.html 수동 적용 (Python이 없는 경우)
- </head> 바로 앞에 추가:
  <link rel="stylesheet" href="./css/polish-v5.42.css?v=20261126-542"/>
- </body> 바로 앞에 추가:
  <script src="./js/polish-v5.42.js?v=20261126-542"></script>
- 기존 js/polish-v5.40.js의 src 쿼리를 ?v=20261126-540-restored 로 변경.
- 블루리본 4회 선정 → 블루리본 5회 선정
- 2025·2026 연속 선정 → 2025·2026·2027 연속 선정
- 기존 소스에 v5.41.css를 직접 연결한 태그가 있다면 제거하세요.
