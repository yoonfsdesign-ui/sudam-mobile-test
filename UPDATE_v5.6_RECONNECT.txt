수담한정식 모바일 메인페이지 v5.6 - 서브페이지 링크 재연결

이 패치는 기존 서버의 서브페이지 파일을 수정하거나 삭제하지 않습니다.
메인페이지의 링크 설정(js/site-config.js)만 다시 연결합니다.

연결 경로
- 수담 → ./about/
- 메뉴 → ./menu/
- 모임 → ./occasions/
- 후기 → ./reviews/
- 예약 → ./reservation/

메인 내부 연결
- 수담의 강점 공간 → ./about/
- 수담의 강점 음식/코스 → ./menu/
- 행사/모임 관련 → ./occasions/
- 진연상/수라상 → ./menu/course/
- 전체 메뉴 보기 → ./menu/
- 코스 상담 → ./reservation/
- 공간 더 보기 → ./about/
- 전체 후기/후기 카드 → ./reviews/

주의
- 개별 모임/후기 상세 페이지의 정확한 서버 slug는 현재 메인 소스에 남아 있지 않아,
  해당 카드는 우선 각 허브 페이지로 연결했습니다.
- 기존 서브페이지 폴더는 그대로 유지됩니다.
