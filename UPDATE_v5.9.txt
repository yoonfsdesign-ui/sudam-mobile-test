수담한정식 모바일 사이트 v5.9 수정사항

[공통]
- 서브페이지 포함 지구본을 동일 SVG 아이콘으로 통일하고 수직 정렬 보정
- 전체 글씨 크기 소폭 상향
- 상단 KR + 아래 화살표를 밝은 황토/브라운 포인트색으로 변경
- 섹션 영문 키커 및 다이아몬드 라인을 더 밝은 포인트색으로 변경
- 모든 페이지 하단 고정 메뉴 문구/아이콘 구조 통일

[메인]
- HERO '소중한 만남에' 확대, '품격을 더하다' 아래 다이아몬드 라인 추가
- 신뢰 영역 좌우 파티클 및 2개 아이콘 확대
- 수담의 강점 '자세히 보기' 밝게 보정
- 모임 4개 카드의 설명 문구 삭제, 제목 확대
- 기본 테마 모임 섹션 이미지 오버레이 투명도 완화
- 진연상/수라상 카드 하단 추천 설명 삭제
- 공간 인테리어 제목 아래 다이아몬드 라인 강화
- 전체 후기 보기 (128) 표시
- 리뷰 2개 카드의 자동전환을 하나의 공통 타이머로 통합
- 모바일 스와이프 + PC 마우스 드래그/휠/키보드 좌우키 지원
- 리뷰 카드의 높이/하단 메타 위치를 고정해 화면 폭 변화 시 레이아웃 흐트러짐 완화

- 키가 비어 있을 때는 images/location-map.jpg 이미지가 표시되며 클릭하면 네이버 지도로 이동
- 네이버 버튼: NAVER Green / 카카오맵 버튼: Kakao Yellow 적용
