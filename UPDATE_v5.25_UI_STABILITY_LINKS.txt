SUDAM v5.25 — 메인 UI 안정화 + 링크 복구 재작성

이번 버전은 v5.24의 HTML 전체 재파싱/재저장 방식을 폐기하고,
v5.23의 정상 DOM 원문을 기준으로 필요한 href만 최소 치환했습니다.

[UI 안정화]
- 메뉴 '전체 메뉴 보기' / 후기 '전체 후기 보기'를 섹션 상단 헤더 행에 고정
- 지도 네이버/카카오 버튼을 지도 이미지/캔버스 아래 별도 행으로 고정
- 카카오 API 실패 시에도 fallback 지도 이미지가 반드시 보이도록 보강
- 지도 자체에는 스크롤 모션을 걸지 않음
- 슬라이더 이전/다음 버튼과 도트 위치를 원래 overlay 위치로 재고정
- 애니메이션은 JS가 실제로 로드된 경우에만 숨김 상태를 사용
- IntersectionObserver/JS 문제가 생겨도 2.6초 뒤 모든 콘텐츠 강제 노출하는 fail-safe 추가
- 기존 2안 웜차콜/오프화이트 대비 디자인은 유지

[링크]
- data-url-key는 그대로 보존
- href에 실제 내부 경로를 직접 넣어 JS가 없어도 이동 가능
- JS가 있으면 동일한 site-config 경로로 다시 설정되므로 충돌 없음
- 수담 / 메뉴 / 모임 / 후기 / 예약
- 강점 3종
- 가족모임 / 상견례 / 단체행사 / 하우스웨딩
- 전체메뉴 / 진연상 / 수라상 / 코스상담
- 공간 자세히보기
- 후기 전체 / 후기 상세 2건
- 제휴문의 / Family Site 수담
- 네이버지도 / 카카오맵

[의존 파일 동봉]
메인에서 참조하는 기존 polish CSS와 Kakao map CSS,
site-config.js/main.js/motion.js를 함께 넣어
기존 파일 누락 때문에 UI가 깨지는 경우도 방지했습니다.

[중요]
- images 폴더 없음
- 사용자가 직접 교체한 이미지/아이콘 파일은 건드리지 않음
- 서브페이지 HTML은 건드리지 않음
