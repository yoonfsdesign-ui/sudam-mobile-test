SUDAM v5.16 — 메인 가독성 / 신뢰 아이콘 / 푸터 / 카카오 아이콘 수정

1. 메인 '품격을 더하다'
- 기존 #FFF0CF가 너무 밝아 흰색에 가깝게 느껴지던 문제 수정
- 기본안은 #E6C693 웜 샴페인 베이지로 변경
- 그림자를 보강해 메인 타이틀로 선명하게 읽히도록 조정
- '소중한 만남에'는 한 단계 낮은 골드로 분리

2. 신뢰 아이콘
- 블루리본과 월계관 PNG의 실제 그림 영역 높이가 달랐던 원인 확인
- 두 이미지를 동일한 투명 캔버스 / 동일한 실제 그림 높이로 정규화한 새 파일 사용
- CSS transform 보정을 제거하여 두 아이콘의 시각적 크기를 안정적으로 통일
- 기존 확대 크기는 유지하고 주변 여백은 추가 축소

3. 푸터 FAMILY SITE
- 푸터 배경과 비슷해지던 텍스트를 밝은 아이보리로 고정
- 버튼 배경/테두리 대비를 보강
- hover/open 상태도 명확하게 구분

4. 하단 카카오톡 상담 아이콘
- 이전 아이콘은 일반 말풍선 SVG였음
- 카카오톡 채널 상담을 인식하기 쉬운 Kakao Yellow + 검정 말풍선 + Ch 형태로 교체
- 하단 고정바에서는 아이콘만 카카오 색상을 사용하고 버튼 배경은 기존 테마 유지

기존 페이지 구조/링크/카카오맵 설정은 변경하지 않습니다.
