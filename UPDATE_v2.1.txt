수담 모바일 가안 v2.1 업데이트 파일

이번 파일은 GitHub Pages 캐시 혼동 방지를 위해 CSS/JS 버전 쿼리를 추가했습니다.

업로드 방법
1. 이 압축을 풉니다.
2. 저장소 Code 화면에서 Add file > Upload files를 누릅니다.
3. 압축 푼 안의 index.html, css, js, images 폴더를 그대로 업로드합니다.
4. 같은 이름 파일 교체를 확인하고 Commit changes 합니다.
5. Actions 탭에서 pages build and deployment가 초록 체크가 될 때까지 기다립니다.
6. 사이트를 새로 열고 Ctrl+F5 합니다.

정상 v2.1 확인 포인트
- 메뉴 영역에 "대표 코스" 표시
- 메뉴 하단 버튼이 "코스 상담하기"
- 리뷰가 2개만 노출
- 지도 내부에 "네이버 지도 / 카카오맵" 버튼
- 예약문의 우측에 "N 네이버 예약"
- 주차·발렛 영역 우측에 건물 사진 영역
